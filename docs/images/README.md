# README用スクリーンショットの置き場所

このフォルダに、プロジェクト直下の README.md で表示する画像を保存します。

## 必要な画像（5枚）

| ファイル名 | 撮影する画面 | URL | 写すとよい内容 |
|---|---|---|---|
| `word-list.png` | 単語・熟語の登録 | http://127.0.0.1:8000/ | 品詞ボタン（例：動詞・形容詞）を選び、その意味の入力欄が開いた登録フォーム |
| `review.png` | 今日の復習 | http://127.0.0.1:8000/review/ | 「答えを見る」を押して、品詞ごとの意味と判定ボタンが表示された状態 |
| `random-setup.png` | ランダム復習の設定 | http://127.0.0.1:8000/random/ | 問題数・復習レベルのボタンと、復習レベルへの反映ルール |
| `random-result.png` | ランダム復習の結果 | 1セットを最後まで回答した後の画面 | 正解数・不正解数・正答率 |
| `dashboard.png` | 学習ダッシュボード | http://127.0.0.1:8000/dashboard/ | サマリーカードと、過去7日間のグラフ・レベル別のグラフ |

ファイル名は上の表のとおりにしてください（README.md がこの名前で画像を読み込みます）。
画像を撮り直したときは、README.md の画像の説明文が、写っている内容と合っているかも確認してください。

## 撮影の手順（Windows）

1. `python manage.py runserver` でアプリを起動し、ブラウザで各画面を開く
2. ブラウザの幅を **1280px 程度** にする（狭すぎると画像が縦長になります）
3. `Windows キー + Shift + S` を押し、画面の必要な範囲を選んで切り取る
4. 表示された通知から「切り取り領域とスケッチ」を開き、保存ボタンで **PNG形式** を選んで、このフォルダ（`docs/images/`）に保存する

画面全体をそのまま撮りたいときは、Chrome の開発者ツール（F12）を開き、`Ctrl + Shift + P` →「Capture full size screenshot」でも保存できます。

- 保存するときの形式は **PNG** にしてください。JPEG で保存したファイルの名前だけを `.png` に変えると、中身と拡張子が一致しなくなります
- `random-result.png` は、ランダム復習を1セット最後まで回答すると表示される画面です。回答すると実際の学習データ（復習レベル・次回復習日・履歴）が更新される点に注意してください

## 公開前の注意

- 画面に **個人情報やパスワードが写っていないか** 確認してください（ブラウザのブックマークバーや、他のタブのタイトルなど）
- 写す単語や例文は、公開しても問題ない学習用のものにしてください
- 1枚あたり **1MB 以下** を目安にしてください（大きい画像はGitHubでの表示が遅くなります）
